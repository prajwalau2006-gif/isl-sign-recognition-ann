## Caveats

- The split is reconstructed/provisional, not the official INCLUDE split.
- Validation examples per class are sparse (1–3).
- Only two seeds were used.
- Signer-independent evaluation is not available.
- These results must not be compared directly with earlier 37.25% test accuracy from a different evaluation procedure.
